# DE/PARA
A nova funcionalidade permite ao usuário realizar o mapeamento de colunas durante processos de importação de dados de forma mais fácil e simplificada, sem a necessidade de alterar o mapeamento criado anteriormente.

Com a nova implementação foi eliminado também a necessidade de mapeamento para Drilldown, podendo fazer a seleção de colunas diretamente pela modal DE/PARA.

Uma vez que a correspondência de colunas é feita, e o passo é salvo, a modal não irá se abrir novamente. Para realizar qualquer manutenção, o usuário deverá clicar no botão "Mapeamentos".
